# streams:make build stage — plan, diff, apply

`streams:make` is the only build command. It loads the app JSON tree, generates code into an in-memory file tree, diffs that tree against the working directory, and then adds or edits files. It never deletes.

## Evidence

- `phpunit.txt` — full `vendor/bin/phpunit` (vendor deprecation noise removed). **60 tests, 2503 assertions, 0 errors, 0 failures, 1 skipped.** The skip is the pre-existing Make Addon test.
- `diff.txt` — unified diff from a dry run of the People fixture (11 created files, nothing written).
- `plan.json` — the `--json` plan for that same run (`created`, `modified`, `skipped`, `unapplied`, `diff`). A real run reports this same plan.
- `second-run.json` — the plan after that run is applied with no tree changes: 0 created, 0 modified.
- `unapplied.json` — the same tree after `PeopleTable.php` was replaced with a managed file that has no class. The file is not written. Each unapplied edit has `path`, `file`, and `reason`.
- `implementation.diff` — the git diff for the implementation (evidence files excluded).

## Acceptance

1. `streams:make --dry-run` prints a unified diff and writes nothing (`StreamsMakeTest::test_dry_run_prints_a_unified_diff_and_writes_nothing`).
2. `--dry-run --json` and the real run list the same created, modified, skipped, and unapplied files (`test_dry_run_json_matches_the_real_run_plan`).
3. A second run with no tree changes reports 0 created and 0 modified (`test_a_second_run_with_no_tree_changes_reports_nothing_created_or_modified`, `second-run.json`).
4. Removing a node leaves its file in place and lists it under `skipped`. Apply only calls `File::put` (`test_removing_a_node_leaves_its_file_and_lists_it_as_skipped`).
5. An edit that cannot apply is reported with path, file, and reason, and the file is left untouched (`test_an_unapplied_edit_reports_path_file_and_reason_and_writes_nothing`, `unapplied.json`).
6. No `streams:build` command, and no `make:page`, `make:action`, or `make:form` command, is registered (`test_no_separate_build_command_is_registered`).

## Notes

Paths default to the GroupVitals reference layout (`app/Domains/People/Panel/Tables/PeopleTable.php`, `app/Domains/People/Panel/Resources/PeoplePanelResource.php`) and can be overridden with `config('streams.sdk.make.paths')`. Class names are the StudlyCase of the dot path, except panels, which use the `Resource` suffix.

The generated class is the build-stage file: the `Generated by streams/sdk` marker, the node path, and a `label()` method. Named transforms stay the way to reshape a reference class. This stage does not delete, and it refuses to overwrite a file it cannot safely edit.

`vendor/bin/phpstan` is not installed in this package. Changed PHP files were formatted with `resources/bin/pint.phar`.
